# Functional Documentation

This section covers the business domain of Project B: domain entities, end-user features, and business workflows.

## Structure

| Folder / File | Purpose |
|---------------|---------|
| `business-objects/` | Domain entities and their relationships |
| `features/` | End-user capabilities and acceptance criteria |

## Getting started

Add a `business-objects/` and a `features/` folder here as the project grows. Each file should document a single entity or feature with its context, behaviour, and edge cases.
